# 🔥 Featured Projects

## 1️⃣ Intelligent Content Ranking & Personalization Engine

📁 content-ranking-system/

A production-style Learning-to-Rank (LTR) platform inspired by modern recommendation and search systems used by large-scale digital platforms.

### Key Features

* Multi-stage retrieval and ranking architecture
* Candidate generation and intelligent re-ranking
* User, content, and contextual feature engineering
* Negative sampling for implicit feedback learning
* Time-aware validation to eliminate data leakage
* Low-latency inference and scalable scoring pipelines
* Industry-standard ranking evaluation framework

### Performance Metrics

* NDCG@K
* MAP (Mean Average Precision)
* Recall@K
* Precision@K

### Tech Stack

Python • LightGBM • XGBoost • Pandas • NumPy • FastAPI • GitHub Actions
